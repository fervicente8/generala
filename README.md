# 🎲 Generala Online

Una versión web de Generala, desarrollada con **Next.js** y **WebSocket**, para jugar con amigos en tiempo real. Disfrutá del clásico juego de dados, ahora con funcionalidades sociales y estadísticas competitivas.

---

## 🚀 Características

- ✅ **Autenticación con Google**
- 🧑‍🤝‍🧑 **Sistema de amigos**: agregá, aceptá y eliminá contactos
- 🕹️ **Salas de juego personalizadas**: públicas o privadas con contraseña
- 📩 **Invitaciones en tiempo real** a partidas
- 🔁 **Actualización en vivo** con WebSocket
- 📊 **Historial de partidas** con:
  - Porcentaje de victorias
  - Valores más frecuentes
  - Estadísticas por categoría
- 🔜 **Sistema de ELO** (en desarrollo)

---

## 🧱 Tecnologías utilizadas

- **Next.js** + **TypeScript**
- **Tailwind CSS**
- **Socket.io** para WebSocket
- **Prisma + PostgreSQL**
- **Auth.js**
- **Lucide React**

---

## 🧪 Probalo

Deployá en **Render** (ver [DEPLOY.md](DEPLOY.md)) y accedé a la URL de tu app. Iniciá sesión con Google y empezá a jugar.
